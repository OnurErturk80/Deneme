# Cem Tetris

iPhone/iPad için tasarlanmış, tek sayfalık Tetris oyunu. Kurulum veya uygulama mağazası gerekmez.

## Telefonda açmak
1. Bu depoyu GitHub Pages ile yayınlayın (Settings → Pages → Branch seçin → Save).
2. Çıkan linki iPhone/iPad'de **Safari** ile açın.
3. Paylaş düğmesi → **Ana Ekrana Ekle**. Artık tam ekran, internetsiz de açılan bir uygulama gibi çalışır.

## Kontroller
- Alttaki büyük düğmeler: sol, aşağı, sağ, döndür, hızlı bırak.
- Tahtada: yana sürükle = hareket, dokun = döndür, aşağı sürükle = hızlı indir.

## Cem'e göre ayarlamak
Oyun içinde ⚙︎ Ayarlar: isim, ten ve saç rengi, saç modeli, gözlük, kolay mod, ses.
"Resim seç" ile kendi hazırladığınız karikatür kullanılabilir; resim yalnızca cihazda saklanır.

## Bilgisayarda denemek
Ok tuşları hareket/döndürme, boşluk hızlı bırak, P mola.
